# Cert Ledger: CompTIA Security+ (SY0-701) study app

Your personal study engine for CompTIA Security+: a diagnostic, reading lessons, swipe flashcards with spaced repetition, quizzes, and readiness tracked against the official exam objectives.

## Run it

No install. Double-click `index.html` (or drag it into Chrome/Edge/Safari). Keep the `data` folder next to it.

Progress is saved in that browser. Use **Progress → Export** to back it up.

## How to use it

1. **Diagnostic** (once, about 15 minutes): 25 questions. Tells you if networking needs work first.
2. **Today** always shows your next step: read → swipe → quiz, one objective at a time.
3. **Swipe**: space reveals, → got it, ← again (or drag the card). Cards come back on a schedule (same day, 1, 3, 7, 14 days).
4. **Review**: due cards from everything you've started, plus questions you got wrong.
5. **Explain it differently**: copies a prompt with the lesson to paste into Claude.

## Content

- Every current CompTIA exam is studyable: Tech+, A+ Core 1 and 2, Network+, Security+ (701 and 801), CySA+, PenTest+, SecurityX, Cloud+, Linux+. Switch from the Certs tab; each exam keeps its own progress.
- All 11 exams have their full official objective lists (from CompTIA's objectives documents).
- Lessons written so far (researched, sources listed on each lesson):
  - Security+ SY0-701 Domain 1 (4 objectives)
  - Tech+ FC0-U71 Domain 1 (4 objectives)
  - A+ Core 1 220-1201 Domain 1 (3 objectives)
- Other domains are researched and written one at a time. Ask Claude in the APP studio project for the next one.
